Project Description:

This project investigates the implementation and performance of fully connected feedforward neural networks built entirely from scratch using NumPy. The primary goal is to develop an understanding of the core mechanisms underlying neural network learning, including forward propagation, backpropagation, and gradient-based optimization. The network is first applied to the Runge function to study its ability to approximate nonlinear relationships and analyze the effects of activation functions, network depth, and learning rates. The implementation is then tested on the Iris dataset to evaluate its classification performance on real data and to compare it with established machine learning libraries. The project further explores how network architecture, such as the number of hidden layers and nodes, influences model accuracy and convergence.
